# Epoch

[![build](https://github.com/databento/epoch/actions/workflows/build.yaml/badge.svg)](https://github.com/databento/epoch/actions/workflows/build.yaml)
[![license](https://img.shields.io/github/license/databento/epoch?color=blue)](./LICENSE)

Epoch is a collection of Unix timestamp conversion tools for anywhere you work. Convert Unix/epoch timestamps to human-readable date strings, with support for seconds, milliseconds, microseconds, and nanoseconds.

- **[epoch-cli](epoch-cli/README.md)** — Convert Unix timestamps from the command line without opening a browser. Pass timestamps directly or pipe in logs and other output. Epoch replaces the timestamps while preserving everything around them.
- **[epoch-extension](epoch-extension/README.md)** — A lightweight Chrome extension for instant timestamp conversion on any webpage. Highlight or select a Unix timestamp to convert, no need to copy it into another tab.
- **[epoch.to](https://epoch.to/)** — A fully featured, bidirectional timestamp converter for the web. Convert between epoch time and human-readable date strings, with autodetection of more than 100 different formats.
